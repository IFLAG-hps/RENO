# 共通エラー処理・認証認可の完了条件

## AI・S3・通知失敗時の入力保持と再試行

AI、S3、通知（SES等）の処理が失敗した場合でも、利用者が入力した相談内容・フォーム入力・選択した写真を失わず、同じ内容で再試行できることを本機能の完了条件とする。

- 一時的なAIサービス障害、AI応答エラー、タイムアウト時に、入力内容と会話履歴を保持する。
- S3の署名付きURL発行、アップロード、保存確認のいずれかが失敗した場合に、選択した写真と入力内容を保持する。
- 通知送信に失敗した場合に、氏名・連絡先・相談内容を保持する。
- 再試行操作を画面上で提供し、保持した入力内容を使って処理を再実行できる。
- 再試行できない入力エラー・認証エラー・認可エラーでは、入力内容を保持したまま原因を表示し、再送による二重登録を発生させない。
- AI・S3・通知の各失敗ケースについて、自動テストまたは手動受入テストで入力保持と再試行成功を確認する。
