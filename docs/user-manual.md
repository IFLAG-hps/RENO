# RENO ユーザーマニュアル

## 1. RENOについて

RENOは、リフォーム相談をAIと対話しながら整理するWebアプリです。現状写真の確認、希望内容のヒアリング、素材候補の確認、概算費用・工期・補助金候補の確認、担当者への相談申込みを行えます。

AIによる画像確認・金額・補助金情報は参考値です。正式な建物診断、見積書、補助金の交付決定を意味しません。最終判断は施工会社・自治体へ確認してください。

## 2. 利用開始

1. RENOのURLをブラウザで開きます。
2. 案内されたPIN、またはメールアドレスとパスワードでログインします。
3. 初回ログインでパスワード変更を求められた場合は、画面の指示に従います。
4. ログイン後、相談したい内容をチャットに入力します。

スマートフォンでは、メニューの「スマホで開く」からQRコードを表示できます。SafariまたはChromeの「ホーム画面に追加」を使うと、PWAとして起動できます。

## 3. 基本操作

### 3.1 リフォーム相談

相談したい部屋、困っていること、希望する雰囲気、予算、時期などを自然文で入力してください。質問に回答するほど、提案内容が具体化します。

### 3.2 現状写真の診断

1. チャットの写真・診断導線を選択します。
2. 室内が明るく写った写真を1枚選択します。
3. 診断結果を確認し、「素材を探す」「概算を見る」「施工後イメージを作る」などの次の操作を選択します。

写真から判断できない場合があります。その場合は別の室内写真を使うか、写真なしで相談を続けてください。個人情報や不要な人物・書類が写り込んだ写真はアップロードしないでください。

### 3.3 素材候補

相談内容に合う素材候補が最大3件表示されます。メーカー、商品名、価格目安、施工実績、参照資料を確認できます。価格や性能は最新カタログ・正式見積で再確認してください。

### 3.4 概算費用・工期・補助金

「概算を見る」を選ぶと、会話内容をもとに費用・工期・補助金候補が表示されます。面積・施工条件が未確定な場合、幅のある概算になります。補助金は申請時期、自治体、予算枠、着工前申請などの条件を必ず確認してください。

### 3.5 担当者への相談

1. 相談内容を確認し、「担当者に相談する」を選びます。
2. 氏名と連絡先を入力します。
3. 内容を確認して送信します。

受付後の連絡時期は運用環境により異なります。デモ・モック環境では受付完了までの画面確認のみで、実際の担当者への送信は行われない場合があります。

## 4. メニュー

- 施工事例を管理：登録済みの施工事例写真の登録・一覧確認・編集。
- ヒアリング履歴：過去の相談セッションを確認。
- キャッシュをリセット：端末内に保存された会話や設定を削除。
- ロック：ログイン画面へ戻る。
- SE音：タップ音・通知音のオン／オフ。

キャッシュのリセットは元に戻せません。必要な相談内容は担当者への申込み前に控えてください。

## 5. 困ったとき

ページを再読み込みし、ログアウト後に再ログインしてください。写真診断だけ失敗する場合は、画像サイズを小さくし、明るく対象が大きく写った写真に変更します。APIエラーが続く場合は、発生時刻、操作内容、表示されたエラー文を添えて管理者へ連絡してください。APIキーやトークンを送らないでください。
