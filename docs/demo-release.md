# 動作デモ完成版の定義

## 位置づけ

2026年9月3日時点の `main` を、写真ベースのリフォーム相談サービスにおける「動作デモ完成版」と定義する。

この版は、利用者が相談開始から提案・概算確認、担当者相談までの画面導線を確認できることを目的とする。MVP本番運用版ではなく、今後の追加実装を検討・確認するための基準版とする。

## 動作デモに含む範囲

- Reactで構成した相談画面、Agent、Mockup、Revenue各画面
- チャット形式の相談フロー
- 写真登録を含む画面上の相談導線
- AI提案、施工事例、素材推薦、概算表示の画面確認
- 担当者相談に至るまでの画面遷移
- PC表示時のスマートフォン用QRコード表示
- QRカードの移動・クリック透過
- 起動時のエージェント画像表示
- 定型アクションのReact内処理

## 本版に含まない範囲

以下は本番MVPに向けた追加実装として、`dev`または`staging`で検証する。

- 写真のS3署名付きアップロードと本番保存
- LambdaによるAI画像生成および生成画像のS3保存
- PDFのS3保存
- 相談内容のDynamoDB保存を画面から一貫して実行する経路
- 相談履歴取得APIと履歴画面の接続
- 担当者相談フォームからの受付API呼び出し
- SESによる担当者通知の本番確認
- AI処理失敗時の再試行・復旧処理
- AWS実環境での写真登録から相談受付までの結合テスト

## 環境の扱い

- `main`：本書で定義する動作デモ完成版。デモ基準として安定性を優先する。
- `staging`：フェーズごとのレビュー用。確認可能な状態で機能を統合する。
- `dev`：追加実装・検証用。開発中の変更を反映する。

追加機能は、原則として `dev` で実装し、レビュー可能になった時点で `staging` に反映する。承認後に `main` へ反映する。

## 更新方針

本版を基準として、今後の変更は動作デモの範囲を壊さないように管理する。MVP本番運用版として公開する場合は、別途MVP完了条件を満たしたことを確認し、リリース内容を更新する。
