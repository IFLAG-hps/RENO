# 要件バックログ

## 関係者検討後に実装する項目

### 補助金判定の精度向上

関係者と制度・業務要件を確認した後、以下を実装する。

- 補助金制度データの項目と更新運用を確定する
- 対象地域、住宅種別、所有形態、築年数、工事内容などを取得する
- 対象工事、対象外条件、補助額、上限、申請期間、併用条件を管理する
- 公式情報のURL、更新日、有効期限、データバージョンを保持する
- ユーザー条件に応じてDBから制度候補を検索する
- DB検索結果を根拠としてAIに説明させる
- 情報不足時は「該当なし」と断定せず、追加質問を表示する
- 自治体独自制度を対象範囲へ含めるか決定する

現状は、国の省エネ関連制度を最小限登録し、候補表示のみを行っている。
